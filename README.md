# EduKSP PRO

Нежный, современный браузерный генератор КСП по структуре Приказа №130 МОН РК.

## Возможности
- Google Gemini / DeepSeek / OpenAI
- Русский, қазақша, English, Ўзбекча (кириллица)
- Подробный и краткий режим
- 4 формата урока
- Инклюзивные задания
- Дескрипторы для ФО
- Наглядные схемы и иллюстрации
- История последних 10 КСП в браузере
- Редактирование готового документа
- Экспорт Word, PDF и печать
- Адаптивный дизайн для телефона и ПК

## Запуск
Просто откройте `index.html` или разместите репозиторий на GitHub Pages.

> Важно: API-ключ вводится непосредственно в браузере. Для публичного production-сайта безопаснее использовать серверный backend/proxy и не хранить секретный ключ на клиенте.

## GitHub Pages
Settings → Pages → Deploy from branch → `main` → `/ (root)`.

## Зависимости
Интерфейс использует CDN Tailwind CSS, Font Awesome, html2pdf.js и сервис генерации иллюстраций. Для полной работы нужен интернет.
