# EduKSP PRO v2

Нежный современный браузерный генератор краткосрочных планов урока (КСП) по структуре Приказа №130 МОН РК.

## Что нового в v2
- Исправлена интеграция Google Gemini: удалена устаревшая `gemini-2.5-flash`.
- Gemini автоматически пробует актуальные GA-модели `gemini-3.8-flash`, затем `gemini-3.7-flash` и `gemini-3.6-flash`.
- Убраны устаревшие sampling-параметры из Gemini-запроса.
- Улучшена обработка HTTP/API ошибок.
- Сохранён нежный фирменный дизайн EduKSP.
- Русский, қазақша, English, Ўзбекча (кириллица).
- Подробный и краткий режим.
- 4 формата урока.
- Инклюзивные задания и дескрипторы ФО.
- Наглядные схемы и иллюстрации.
- История последних 10 КСП.
- Редактирование готового документа.
- Экспорт Word, PDF и печать.
- Адаптивная работа на телефоне и ПК.

## Запуск
Откройте `index.html` или разместите репозиторий на GitHub Pages.

## GitHub Pages
Settings → Pages → Deploy from branch → `main` → `/ (root)`.

## Важно про API-ключ
Ключ вводится непосредственно в браузере и сохраняется в localStorage этого браузера. Для публичного production-сайта безопаснее использовать серверный backend/proxy и ограничить ключ по источнику/API. Не публикуйте сам ключ в GitHub.

## Зависимости
Проект использует CDN Tailwind CSS, Font Awesome, html2pdf.js и сервис генерации иллюстраций. Для полной работы нужен интернет.

## Новое в PRO v2.1
- **Интеграция конспекта** — вставьте готовый конспект/материалы, и AI распределит их по этапам КСП и сформирует полный интегрированный конспект.
- **Семинар — полностью** — полноценная программа семинара, сценарий ведущего, теоретические блоки, практические задания, кейсы, обсуждение, материалы, контроль понимания и рефлексия.
- Добавлен формат **Семинар / тренинг** без удаления прежних форматов.


## Обновление v2.2
- Для узбекского языка (кириллица) готовый документ локализуется целиком: школа/организация, педагог, предмет, класс, дата, тема, цели, этапы, действия, оценивание, ресурсы, подписи таблиц, конспект и семинарские разделы.
- Добавлена усиленная инструкция ИИ: если значения школы/предмета/темы введены по-русски при выборе узбекского, модель переводит общий текст на узбекский, сохраняя имена, бренды, официальные названия и номера.
- OpenAI обновлён с устаревшего `gpt-4o-mini` на `gpt-5.6-luna` и переведён на Responses API.
- Сохранены Gemini, DeepSeek, интеграция конспекта, полный семинар, история, Word/PDF и наглядности.
